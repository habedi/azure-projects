## Projects

This directory contains standalone projects for learning and developing with Microsoft Azure services.

| #  | Project Name                                       | Domain           | Primary Azure Services                       | Complexity   | Short Description                                                                         |
|----|----------------------------------------------------|------------------|----------------------------------------------|--------------|-------------------------------------------------------------------------------------------|
| 01 | [Blob storage round trip](01-blob-storage)         | Data Engineering | Azure Blob Storage                           | Beginner     | Upload, download, verify, and delete a blob in sandbox storage.                           |
| 02 | [Medallion lakehouse](02-fabric-lakehouse)         | Data Engineering | Microsoft Fabric, OneLake                    | Intermediate | Ingest, clean, aggregate, and verify data in Microsoft Fabric OneLake.                    |
| 03 | [Event streaming ingestion](03-event-streaming)    | Data Engineering | Azure Event Hubs, Data Lake Storage Gen2     | Intermediate | Ingest, stream, process, and persist telemetry events into Azure Data Lake Storage Gen2.  |
| 04 | [Retrieval-augmented generation](04-rag-ai-search) | AI Engineering   | Azure AI Search, OpenAI, Blob Storage        | Intermediate | Ingest, chunk, vectorize, index, and retrieve grounded answers with citations.            |
| 05 | [Change data capture](05-change-data-capture)      | Data Engineering | Cosmos DB, OpenAI, Table and Blob Storage    | Intermediate | Ingest mutations, enrich changes with GPT-6 Luna, and synchronize materialized views.     |
| 06 | [Document processing](06-document-processing)      | AI Engineering   | Azure AI Document Intelligence, Blob Storage | Intermediate | Ingest invoices, extract fields with prebuilt AI models, validate schemas, and save JSON. |
