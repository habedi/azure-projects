## Projects

This directory contains standalone projects for learning and developing with Microsoft Azure services.

| #  | Project Name                                    | Domain           | Primary Azure Services                                          | Complexity   | Short Description                                                                                                    |
|----|-------------------------------------------------|------------------|-----------------------------------------------------------------|--------------|----------------------------------------------------------------------------------------------------------------------|
| 01 | [Blob storage round trip](01-blob-storage)      | Data Engineering | Azure Blob Storage                                              | Beginner     | Upload, download, verify, and delete a blob in sandbox storage (using OpenTofu and Python).                          |
| 02 | [A medallion lakehouse](02-fabric-lakehouse)    | Data Engineering | Microsoft Fabric, OneLake                                       | Intermediate | Ingest, clean, aggregate, and verify data in Microsoft Fabric OneLake (using OpenTofu and Python).                   |
| 03 | [Event streaming ingestion](03-event-streaming) | Data Engineering | Azure Event Hubs, Azure Functions, Azure Data Lake Storage Gen2 | Intermediate | Ingest, stream, process, and persist telemetry events into Azure Data Lake Storage Gen2 (using OpenTofu and Python). |
